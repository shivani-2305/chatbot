# GenAI chatbot
A Generative AI chatbot built with Python and the Gemini API. It understands user questions and gives human-like answers
# Features
-Natural conversation using LLM
-Remembers chat history for better replies
-simple to run in google colab
# Tools used
-Python
-Google Gemini API
-Google Colab
# How To Run
1.Open the notebook in Google Colab
2.Add your Gemini API Key in Colab
3.Run all the Cells
4.Type a message and start chatting
